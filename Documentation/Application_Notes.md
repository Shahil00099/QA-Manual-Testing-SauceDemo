# Application Notes

## Application Name
SauceDemo

## URL
https://www.saucedemo.com/

## Purpose
SauceDemo is a demo e-commerce application used for practicing manual and automated software testing.

## Modules Identified
- Login
- Inventory (Products)
- Product Details
- Shopping Cart
- Checkout
- Hamburger Menu

## Observations
- Users must log in before accessing products.
- Products can be sorted.
- Items can be added to and removed from the cart.
- Checkout requires user information.

# Test Plan

This folder contains the test plan for the SauceDemo manual testing project.

# Test Plan – SauceDemo

## Project
SauceDemo Manual Testing

## Objective
To verify that the core functionalities of the SauceDemo application work as expected and to identify any defects.

## Scope

The following modules will be tested:

- Login
- Product Inventory
- Product Details
- Shopping Cart
- Checkout
- Navigation Menu

## Testing Type

- Manual Testing
- Functional Testing
- UI Testing
- Negative Testing

## Browser

- Google Chrome

## Test Environment

- Windows 11
- Chrome Browser

## Entry Criteria

- Application is accessible.
- Test credentials are available.

## Exit Criteria

- All planned test cases are executed.
- Bugs are documented.
- Test summary is completed.

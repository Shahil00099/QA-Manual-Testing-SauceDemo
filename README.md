# QA Manual Testing - SauceDemo

This repository contains my first manual QA testing project using the SauceDemo web application.

The objective of this project is to demonstrate the complete manual testing process, including:

- Requirement understanding
- Test planning
- Test case design
- Test execution
- Bug reporting
- Test summary
